# AiLinkAny on LobeHub

Connect to `https://mcp.ailinkany.com/mcp` using Streamable HTTP and independent AiLinkAny account OAuth. Do not insert static administrator credentials, a shared access token, or a Device Token.

The controlled Windows computer needs the AiLinkAny client from https://ailinkany.com/ and must be bound to the user's own account. Review tool calls and restrict work to authorized devices and paths. Actual computer execution requires an eligible subscription; registration, OAuth and device discovery are separate from execution entitlement.

The public manifest includes representative, read-only device discovery, diagnosis and task-status tool metadata. The complete live tool catalog is discovered from the remote server after account authorization; it is not replaced by the samples in the listing. The client and cloud implementation remain proprietary.

Listing publication, LobeHub account/GitHub publisher verification, and end-user MCP OAuth are separate steps. Do not claim LobeHub connection or marketplace publication has passed until the corresponding result is observed.
