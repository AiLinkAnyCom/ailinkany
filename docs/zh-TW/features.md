# AiLinkAny 功能介紹

AiLinkAny 讓 AI 與工作電腦脫鉤：無論 AI 在網頁上、任何一台電腦的桌面用戶端中，還是在遠端伺服器的命令列裡執行，都能安全存取你的本機開發機。

## 連線與安全
- 託管的雲端中繼：不需要通道、連接埠轉送或公用 IP。
- OAuth 2.1 登入，不需要 API 金鑰；AI 的 OAuth 權杖與裝置權杖彼此隔離。
- 授權資料夾控管與工具呼叫稽核紀錄。
- 指令冪等（指令 ID），網路重試不會讓同一道指令執行兩次。

## 檔案、命令列與系統
- 檔案讀寫與搜尋、命令列、互動式與長時間執行的程序。
- 系統資訊、連接埠清單、連線診斷。

## 文件處理
- 讀取 Excel/PDF/DOCX；產生 PDF；編輯 PDF 頁面與 Excel 範圍，全部在本機完成，不需要 Office。

## Git
- status / diff / log。
- 合併前預測衝突、無衝突才合併、禁止強制推送，並提供 worktree 與儲存庫整理輔助工具。

## 程式設計代理
- 從網頁版 AI 把任務交給本機的 Codex、Claude Code 或 OpenCode；支援 AI 工作階段交接與多工作階段協作。

## MCP 閘道
- 透過 AiLinkAny 網址管理並存取本機其他 MCP 伺服器。

## 網路工程
- SSH（支援私密金鑰）、Telnet 與序列埠連線，可儲存連線設定檔。

## 監控
- AI 停止向主機傳送指令時寄送電子郵件提醒。

## 桌面用戶端
- Rust/Tauri 圖形介面，用於登入、裝置綁定、授權資料夾、網路設定檔與 MCP 閘道設定。單一檔案免安裝 EXE。
