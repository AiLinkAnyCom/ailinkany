# AiLinkAny features

## Connection & security
- Hosted cloud relay — no tunnel, port forwarding or public IP.
- OAuth 2.1 sign-in, no API key; AI OAuth tokens isolated from device tokens.
- Authorized-folder control and tool-call audit log.
- Command idempotency (command IDs) so network retries don't run a command twice.

## Files, shell & system
- File read/write/search, shell commands, interactive and long-running processes.
- System information, port listing, connection diagnostics.

## Documents
- Read Excel/PDF/DOCX; create PDFs; edit PDF pages and Excel ranges — locally, no Office required.

## Git
- status / diff / log.
- Conflict prediction before merge, merge only when conflict-free, force push blocked, worktree and repo hygiene helpers.

## Coding agents
- Dispatch tasks from a web AI to local Codex, Claude Code or OpenCode; AI session handoff and multi-session collaboration.

## MCP Gateway
- Manage and reach other local MCP servers through the AiLinkAny endpoint.

## Network engineering
- SSH (including private keys), Telnet and serial connections with saved profiles.

## Monitoring
- Email alert when the AI stops sending commands to your host.

## Desktop client
- Rust/Tauri GUI for sign-in, device binding, authorized folders, network profiles and MCP Gateway settings. Portable single EXE.

## Platforms
- Windows 10/11. Linux: in development, not yet released.

In total, AiLinkAny exposes 100+ MCP tools. Details: https://ailinkany.com
