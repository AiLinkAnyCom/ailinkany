# AiLinkAny の機能

AiLinkAny は AI と作業用コンピューターを切り離します。AI が Web 上、任意のコンピューターのデスクトップクライアント、リモートサーバーの CLI のどこで動いていても、ローカルの開発マシンに安全にアクセスできます。

## 接続とセキュリティ
- ホスト型クラウドリレー：トンネル、ポート転送、グローバル IP は不要。
- OAuth 2.1 サインイン、API キー不要。AI の OAuth トークンとデバイストークンは分離。
- 許可フォルダーの制御とツール呼び出しの監査ログ。
- コマンドの冪等性（コマンド ID）により、ネットワーク再試行で同じコマンドが二重実行されません。

## ファイル、シェル、システム
- ファイルの読み書きと検索、シェルコマンド、対話型・長時間実行プロセス。
- システム情報、ポート一覧、接続診断。

## ドキュメント
- Excel/PDF/DOCX の読み取り、PDF の作成、PDF ページや Excel 範囲の編集をローカルで実行。Office 不要。

## Git
- status / diff / log。
- マージ前の競合予測、競合がない場合のみマージ、強制プッシュのブロック、worktree やリポジトリ整理の補助。

## コーディングエージェント
- Web 版 AI からローカルの Codex、Claude Code、OpenCode にタスクを依頼。AI セッションの引き継ぎや複数セッションでの協調にも対応。

## MCP ゲートウェイ
- AiLinkAny のエンドポイント経由で、ローカルの他の MCP サーバーを管理・利用。

## ネットワークエンジニアリング
- SSH（秘密鍵対応）、Telnet、シリアル接続。接続プロファイルを保存可能。

## 監視
- AI からホストへのコマンドが止まるとメールで通知。

## デスクトップクライアント
- サインイン、デバイス登録、許可フォルダー、ネットワークプロファイル、MCP ゲートウェイ設定のための Rust/Tauri GUI。ポータブルな単一 EXE。

## プラットフォーム
- Windows 10/11。Linux：開発中（未リリース）。

AiLinkAny は合計 100 以上の MCP ツールを提供します。詳細：https://ailinkany.com
